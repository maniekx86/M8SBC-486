M8SBC-486 SeaPig BIOS A2.03 memory map

Memory (normal, M8SBC-486):
|----------------------------------------| 0x500000
|          Extended RAM (384KB)          | 
|----------------------------------------| 0x4A0000
|               Unmapped                 |
|----------------------------------------| 0x400000 (4MB)
|                                        |
|           Extended RAM (3MB)           |
|                                        |
|----------------------------------------| 0x100000 (1MB)
|               BIOS ROM                 |
|----------------------------------------| 0xF0000
|        Add-on ROMs (Video BIOS, etc)   |
|----------------------------------------| 0xC0000
|               Video RAM                |
|----------------------------------------| 0xA0000
|                                        |
|        Conventional RAM (640KB)        |
|                                        |
|----------------------------------------| 0x00500
|     BIOS Data Area (copied from ROM)   |
|----------------------------------------| 0x00400
|     Interrupt Vector Table (IVT)       |
|     - Written by BIOS at startup       |
|----------------------------------------| 0x00000

RAM assigned for BIOS C code: 0x0500 - 0x10000 (base 64KB)

BIOS ROM:
|-------------------------------------| 0xFFFF 
|  Reset vector                       |
|-------------------------------------| 0xFFF0
|  Misc (VGA, INT 15h vectors)        |
|-------------------------------------| 0xF000
|  C code                             |
|-------------------------------------| 0x4000
|  Padding                            |
|-------------------------------------| ????? 
|  BIOS Data & more entry code        |
|-------------------------------------| 0x1E6E
|  CGA Font (1024 bytes)              |
|-------------------------------------| 0x1A6E
|  NOP padding (0x90)                 |
|-------------------------------------| ?????
|  Entry code                         |
|-------------------------------------| 0x0100
|  INT15 & VGA jmp near vectors       |
|-------------------------------------| 0x00FA
|  BIOS Data Block template           |
|-------------------------------------| 0x0000

Important BIOS memory addresses:
0x05F0 - 0x05F3: Saved EDX after reset (CPUID)
0x0600 - 0x0601: Real mode saved SP pointer
0x0602 - 0x0AFF: C stack area (1278 bytes)
0x0B00 - 0x0FFF: Real mode stack (1280 bytes)
0x1000 - 0xFFFF: C variables area (about 60 KB)
